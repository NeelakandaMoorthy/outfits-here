# Outfits Here - Quick Start Guide

Get your affiliate fashion website live in **15 minutes**.

## 🏃 Super Fast Setup (15 min)

### Step 1: Prepare (2 min)
1. Create free account on [Vercel.com](https://vercel.com)
2. Create GitHub account (free)

### Step 2: Deploy (3 min)
```bash
# Clone this project
git clone <repo-url>
cd outfits-here

# Deploy to Vercel (login when prompted)
npm i -g vercel
vercel
```

Your site is LIVE! 🎉

### Step 3: Add Your Products (5 min)
1. Visit: `yoursite.com/admin`
2. Fill product form with:
   - Product name
   - Price
   - Affiliate URL (from Amazon Associates)
   - Image URL
   - Category

3. Add 5-10 products

### Step 4: Configure (5 min)
1. Edit `app/layout.js` - Update site title & description
2. Edit `components/Footer.js` - Add your Pinterest link
3. Update `SAMPLE_PRODUCTS` in `lib/products.js` with your products

That's it! 🚀

## 📱 Setup Pinterest

### Step 1: Create Business Account
- Go to https://business.pinterest.com
- Verify website (add meta tag)
- Create boards:
  - Men's Fashion
  - Women's Fashion
  - Shoes
  - Accessories
  - Trending

### Step 2: Create Pins
- Create pins with vertical images (2:3 ratio)
- Add link to your website
- Pin at least 5x daily

### Step 3: Link Bio
- Set Pinterest bio link to: `yoursite.com`
- Users click bio → Land on your homepage

## 💰 Set Up Affiliate Links

### Amazon Associates (Easiest)
1. Go to https://associate-program.amazon.in
2. Sign up
3. Get affiliate tag (ID)
4. For any product, create affiliate link:
   ```
   https://amazon.in/s?k=product-name&tag=YOUR_TAG
   ```

### Add to Website
1. Visit `/admin`
2. Paste affiliate URL
3. Add product

## 📊 Track Performance

## 🚨 Common Issues

### Products Not Showing
- Check image URLs are valid
- Verify affiliate URLs have `http://` or `https://`
- Refresh page (Ctrl+Shift+R)

### Admin Page Blank
- Clear browser cache
- Try incognito mode
- Check browser console for errors

### Slow Loading
- Images too large (compress)
- Try different browser
- Check internet speed

### Analytics Empty
- Analytics tracks after first visit
- Check browser allows localStorage
- Visit pages to generate events
